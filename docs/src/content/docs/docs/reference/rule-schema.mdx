## Top-level fields

| Field | Type | Description |
|---|---|---|
| `rules` | map of `#SecretRule` | The rules. The field name is the rule ID. |
| `overrides` | map of `#Override` | Disable or re-grade a rule by ID. |
| `config` | `#Config` | Scan settings. |
| `allowlist` | `#Allowlist` | Suppressions for false positives. |

## `#SecretRule` defaults

| Field | Default |
|---|---|
| `kind` | `"pattern"` |
| `severity` | `"HIGH"` |
| `enabled` | `true` |
| `secretGroup` | `1` |
| `entropy.minLen` | `16` |
| `config.maxFileSize` | `2097152` (2 MiB) |
