# 2026-11-12 Thursday

## Morning

- Planned Whac-a-Leak from a design brief (CUE "lattice" rules, rule self-tests, structural scanning, fingerprints, Aho-Corasick). Kept most of it and changed four things: CUE runs only at load time ([ADR-0003](/decisions/adr-0003-cue-at-load-time-only-the-scan-engine-is-plain-go--01a1d2c5075d.md)), layering through default markers because unification is monotonic ([ADR-0004](/decisions/adr-0004-rules-are-keyed-by-id-and-layered-with-cue-default-markers--01a1d2c50766.md)), lightweight Go extractors instead of the CUE runtime for config files ([ADR-0005](/decisions/adr-0005-structured-files-are-parsed-by-lightweight-go-extractors-not-the-cue-runtime--01a1d2c50770.md)), and charset-aware entropy, since a flat 4.3 can never flag hex ([ADR-0006](/decisions/adr-0006-entropy-thresholds-are-charset-aware--01a1d2c50779.md)).
- Scope: v1 scans the filesystem, staged changes and git history; the CLI uses Cobra. The binary is named `wal`. Note that pywal also installs a `wal` binary, which could clash on `$PATH`.

## Notes

- The Makefile's `lint` and `test` targets skip while the module has no packages, because `golangci-lint` errors on "no go files". They run for real from Milestone 1.

## End of Day

- Milestone 0 green: `make wiki`, `make vet-cue lint test` (skeleton), `make docs-build` (8 pages; the logo is optimized from 4.1 MB to 46–332 kB WebP). Landing page checked in dark, light and mobile.
- The docs theme uses the logo's arcade amber, with forest green in the callout gradient and signal red reserved for findings. The landing demo shows a real CUE rule for a fictional *Acme* provider; the scan panel says "coming soon" until Milestone 2/5.
- Renamed the binary `wal` → **`whac`** because of the pywal clash. `.whac/`, `package whac`, `whac1:` and `whac:ignore` follow it, recorded as Amendment 1 to [ADR-0002](/decisions/adr-0002-pure-go-with-cgo-enabled0-and-a-cobra-cli--01a1d2c50754.md). (Entries above keep the old name as written at the time.)
- Added Milestone 6, agent-context preflight ([ADR-0011](/decisions/adr-0011-agent-context-preflight-scans-the-environment-and-credential-files-never-process-memory--01a1d2cc210e.md), [ISSUE-006](/issues/issue-006-agent-context-preflight-environment-credential-files-and-exposure-checks--01a1d2cc2118.md)): environment variables and well-known credential files in scope, plus credential-socket exposure findings. IMDS is opt-in (amends ADR-0008); process memory is out (ptrace/root, looks like credential-dumping malware, wrong threat model). whac audits a context; the environment builder makes it clean.
- Milestone 0 committed (86266aa) and pushed to the new public repo https://github.com/infrashift/whac-a-leak. Pages uses the GitHub Actions source; the first deploy failed before Pages was enabled and passed on rerun. The site is live at https://infrashift.github.io/whac-a-leak/.
- Follow-up: `actions/checkout@v4`, `deploy-pages@v4` and setup-bun target the deprecated Node.js 20. Bump them in a later milestone (vizzini has the same warnings).
- New rule: all documentation follows ASD-STE100. A fork rewrote the docs site, README, PLAN.md, CLAUDE.md and the wiki. `make docs-style` (`scripts/ste-check.py`) checks banned words and sentence length.
- Milestone 1 done ([ISSUE-001](/issues/issue-001-rule-schema-cue-loader-and-rules-verify--01a1d2c507b1.md)). The spike found two problems. First, `cue/load` with an Overlay needs a directory on disk, so an in-memory build instance replaces it ([ADR-0012](/decisions/adr-0012-load-layers-as-one-in-memory-cue-build-instance--01a1d2e388a9.md)). Second, a builtin rule has a concrete severity, so `rules: X: severity` in a layer conflicts. The `overrides` map fixes this ([ADR-0004](/decisions/adr-0004-rules-are-keyed-by-id-and-layered-with-cue-default-markers--01a1d2c50766.md) amendment).
- Learned: Shannon entropy is limited by length as well as alphabet. The default threshold is now `0.75 × log2(min(n, k))` ([ADR-0006](/decisions/adr-0006-entropy-thresholds-are-charset-aware--01a1d2c50779.md) amendment).
- Learned: the installed golangci-lint (built with go1.26) cannot type-check the go1.27 standard library. The Makefile now runs v2.15.0 through `go run`.
- Milestone 1 committed (ed72f9d).
- Milestone 2 done ([ISSUE-002](/issues/issue-002-scan-engine-filesystem-source-fingerprints-and-allowlist--01a1d2c507bb.md)): `whac scan`, `whac allow add`, fingerprints, allowlists, text and JSON reports, the test corpus and golden report.
- Learned: running a candidate regex over the whole file gives 24 MB/s. Line windows around keyword hits give 245 MB/s ([ADR-0013](/decisions/adr-0013-regexes-run-on-keyword-line-windows--01a1d2f04316.md)). PEM keys need `multiline: true`; verification enforces it.
- Learned: a leftmost-longest Aho-Corasick prefilter can hide an overlapping keyword. Overlapping StandardMatch iteration fixes it.
- The landing page now shows real `whac scan` output (`make docs-demo`).
