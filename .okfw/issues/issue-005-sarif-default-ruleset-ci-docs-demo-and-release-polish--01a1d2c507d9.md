# ISSUE-005: SARIF, default ruleset, CI, docs demo and release polish

**Status/Milestone:** Closed · Milestone 5

## Acceptance Criteria
- [x] SARIF 2.1.0 output with `partialFingerprints`. A test validates it against the schema.
- [x] About 30 builtin rules: AWS, GCP service-account JSON, Azure, GitHub, GitLab, Slack, Stripe, Twilio, SendGrid, npm, PyPI, Docker auth, PEM private keys, JWT, generic.
- [x] `.github/workflows/ci.yml` runs `make lint vet-cue test build` and `whac scan --git` on its own repo.
- [x] `docs/src/demo/gen.go` generates the landing-page demo with whac itself. The demo replaces the placeholder panel. Done early in Milestone 2 as `make docs-demo` (no Go generator needed).
- [x] The remaining docs pages (*CI & SARIF*, *Default Rules*) and the README.
- [x] The docs publish the benchmark results.

## Resolution
Done on 2026-11-12. `make lint vet-cue test build docs-style wiki docs-build` all pass, also with Go 1.25.0 (the `go.mod` minimum that CI uses).

- SARIF 2.1.0 writer in `internal/report/sarif.go`. A test validates it against the vendored OASIS JSON Schema through CUE `encoding/jsonschema`. A guard test proves that the schema rejects a log without `version`.
- 30 builtin rules with 84 samples. CUE assembles the samples for push-protected formats at load time ([ADR-0015](/decisions/adr-0015-assemble-push-protected-samples-and-allowlist-fixtures-for-the-self-scan--01a1d3073ff8.md)). The CUE-side `mustMatch` check found two sample length errors before any Go test ran.
- `.github/workflows/ci.yml`: `make lint vet-cue test build docs-style`, `whac rules verify`, `whac scan --git .` (fails on findings), and SARIF upload to code scanning. The docs workflow moved to checkout v7, withastro/action v6 and deploy-pages v5 (no Node 20 warnings).
- The repository scans clean: work tree and history. `.whac/repo.cue` and `.whac/allowlist.cue` hold the fixture allowlists.
- Docs: *CI & SARIF*, *Default Rules* (generated by a test from the rule files), *Benchmarks*, README.
- Measured: startup 12 ms with 30 rules; 183 MB/s scan throughput.
